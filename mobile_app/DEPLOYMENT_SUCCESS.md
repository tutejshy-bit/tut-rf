## 🚀 Способы установки на телефон

### Способ 1: Ручная установка (рекомендуется)
1. **Скопируйте APK файл** на телефон:
   - Через USB кабель в папку Downloads
   - Через облачное хранилище (Google Drive, Dropbox)
   - Через файловый менеджер

2. **На телефоне:**
   - Откройте файловый менеджер
   - Найдите `app-release.apk`
   - Нажмите на файл
   - Разрешите установку из неизвестных источников
   - Установите приложение

### Способ 2: Через ADB (если устройство подключено)
```bash
# Перезапустить ADB
adb kill-server
adb start-server

# Проверить устройства
adb devices

# Установить APK
adb install build\app\outputs\flutter-apk\app-release.apk
```

### Способ 3: Через Flutter (если устройство видно)
```bash
# Проверить устройства
flutter devices

# Запустить на устройстве
flutter run -d [DEVICE_ID]
```

## 🔧 Настройка телефона для установки

### Если APK не устанавливается:

1. **Включите установку из неизвестных источников:**
   - Настройки → Безопасность → Неизвестные источники
   - Или Настройки → Приложения → Специальный доступ → Установка неизвестных приложений

2. **Для Android 8+ (API 26+):**
   - Настройки → Приложения → Специальный доступ
   - Установка неизвестных приложений
   - Выберите файловый менеджер и разрешите установку
