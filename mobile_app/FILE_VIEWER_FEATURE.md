# File Viewer Feature

## Описание
Реализован полноэкранный экран для просмотра и загрузки файлов с ESP устройства.

## Новые компоненты

### 1. FileViewerScreen (`lib/screens/file_viewer_screen.dart`)
Полноэкранный экран для просмотра файлов с ESP с возможностью:
- **Просмотр содержимого** в трех режимах:
  - Content (умный просмотр по типу файла)
  - Hex (шестнадцатеричное представление)
  - Raw (сырое содержимое)
- **Загрузка файла** с прогресс-баром
- **Сохранение на устройство** через диалог выбора файла
- **Копирование в буфер обмена**
- **Автоматическое определение типа файла** и соответствующее отображение

### 2. FilePreviewWidget (`lib/widgets/file_preview_widget.dart`)
Виджет для предварительного просмотра содержимого файла:
- Ограниченный предварительный просмотр (500 символов)
- Умная обрезка для JSON файлов
- Цветовая индикация по типу файла
- Отображение размера файла

### 3. Расширенный BleProvider
Добавлены методы для работы с файлами:
- `readFileContent(String filePath)` - чтение содержимого файла
- `downloadFile(String filePath, {Function(double progress)? onProgress})` - загрузка с прогрессом
- `_clearChunkBuffers()` - очистка буферов чанков

## Поддерживаемые типы файлов

### Умный просмотр:
- **JSON** - форматированный вывод с подсветкой синтаксиса
- **TXT/LOG** - текстовый просмотр
- **SUB** - файлы SubGHz с иконкой радио
- **BIN/HEX** - шестнадцатеричное представление
- **Изображения** - заглушка с возможностью переключения на текст

### Иконки и цвета:
- 📄 TXT/LOG - синий
- 🔧 JSON - оранжевый  
- 📻 SUB - фиолетовый
- 💾 BIN/HEX - красный
- 🎵 WAV/MP3 - зеленый
- 🖼️ Изображения - бирюзовый
- 📦 Архивы - коричневый

## Функциональность

### Навигация
- Нажатие на файл в `FilesScreen` автоматически открывает `FileViewerScreen`
- Нажатие на директорию показывает информацию о папке

### Загрузка файлов
- Кнопка "Download" с прогресс-индикатором
- Автоматическое сохранение через диалог выбора файла
- Fallback сохранение в Documents директорию
- Резервное копирование в буфер обмена

### Обработка ошибок
- Таймауты для чтения файлов (30 сек) и загрузки (60 сек)
- Graceful fallback при ошибках сохранения
- Информативные сообщения об ошибках

## Использование

### Переход к просмотру файла:
```dart
Navigator.of(context).push(
  MaterialPageRoute(
    builder: (context) => FileViewerScreen(
      fileItem: fileItem,
      filePath: '/path/to/file',
    ),
  ),
);
```

### Чтение файла через BleProvider:
```dart
final content = await bleProvider.readFileContent('/path/to/file');
```

### Загрузка файла с прогрессом:
```dart
final content = await bleProvider.downloadFile(
  '/path/to/file',
  onProgress: (progress) {
    print('Download progress: ${(progress * 100).toInt()}%');
  },
);
```

## Архитектура

```
FilesScreen
    ↓ (tap file)
FileViewerScreen
    ↓ (load content)
BleProvider.readFileContent()
    ↓ (ESP command)
ESP32 Transport Layer
    ↓ (chunked response)
BleProvider (chunk assembly)
    ↓ (complete content)
FileViewerScreen (display)
```

## Особенности реализации

1. **Чанкинг**: Поддержка больших файлов через систему чанков
2. **Асинхронность**: Все операции чтения/записи асинхронные
3. **Обработка ошибок**: Многоуровневая система fallback
4. **UX**: Прогресс-бары, индикаторы загрузки, информативные сообщения
5. **Производительность**: Кеширование и оптимизированное отображение

## Совместимость
- Работает с существующей системой команд ESP32
- Совместимо с Binary Protocol транспортного слоя
- Поддерживает все типы файлов, которые может прочитать ESP32
