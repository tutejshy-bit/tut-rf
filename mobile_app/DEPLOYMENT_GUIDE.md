# 📱 Руководство по деплою на Android устройство

## 🔧 Настройка устройства для отладки

### 1. Включение режима разработчика
1. Откройте **Настройки** на Android устройстве
2. Перейдите в **О телефоне** (About phone)
3. Найдите **Номер сборки** (Build number)
4. **Нажмите 7 раз** на номер сборки
5. Появится сообщение "Вы стали разработчиком!"

### 2. Включение USB отладки
1. Вернитесь в главные **Настройки**
2. Найдите **Параметры разработчика** (Developer options)
3. Включите **Отладка по USB** (USB debugging)
4. Включите **Установка по USB** (Install via USB)

### 3. Подключение устройства
1. Подключите телефон к компьютеру через USB
2. На телефоне появится диалог "Разрешить отладку по USB?"
3. **Поставьте галочку** "Всегда разрешать с этого компьютера"
4. Нажмите **OK**

## 🚀 Способы деплоя

### Способ 1: Прямой запуск (рекомендуется)
```bash
# Проверить устройства
flutter devices

# Запустить на устройстве
flutter run -d [DEVICE_ID]
```

### Способ 2: Сборка APK файла
```bash
# Собрать APK
flutter build apk --release

# APK будет в: build/app/outputs/flutter-apk/app-release.apk
```

### Способ 3: Установка через ADB
```bash
# Установить APK на устройство
adb install build/app/outputs/flutter-apk/app-release.apk
```

## 🔍 Диагностика проблем

### Если устройство не видно:
```bash
# Перезапустить ADB сервер
adb kill-server
adb start-server

# Проверить устройства
adb devices
```

### Если Flutter не видит устройство:
```bash
# Проверить статус Flutter
flutter doctor

# Проверить устройства с таймаутом
flutter devices --device-timeout 10
```

## 📋 Пошаговая инструкция

### Шаг 1: Подготовка устройства
1. ✅ Включить режим разработчика
2. ✅ Включить USB отладку
3. ✅ Подключить устройство
4. ✅ Разрешить отладку на устройстве

### Шаг 2: Проверка подключения
```bash
# В PowerShell
adb devices
# Должно показать: [DEVICE_ID] device
```

### Шаг 3: Запуск приложения
```bash
# В папке mobile_app
flutter run -d [DEVICE_ID]
```

## 🎯 Альтернативные способы

### Если USB не работает:

1. **Сборка APK и установка вручную:**
   ```bash
   flutter build apk --release
   # Скопировать APK на телефон и установить
   ```

2. **Использование эмулятора:**
   ```bash
   flutter emulators
   flutter emulators --launch [EMULATOR_NAME]
   ```

3. **Запуск на Web (для тестирования UI):**
   ```bash
   flutter run -d chrome
   ```

## ⚠️ Важные замечания

- **USB кабель** должен поддерживать передачу данных (не только зарядку)
- **Драйверы** должны быть установлены для вашего устройства
- **Безопасность** - разрешайте отладку только с доверенных компьютеров
- **Первый запуск** может занять 5-10 минут (установка компонентов)

## 🔧 Устранение проблем

### Проблема: "Device not authorized"
**Решение:** Проверьте диалог на телефоне и разрешите отладку

### Проблема: "No devices found"
**Решение:** 
1. Проверьте USB кабель
2. Перезапустите ADB: `adb kill-server && adb start-server`
3. Проверьте настройки разработчика

### Проблема: "Build failed"
**Решение:**
1. Очистите проект: `flutter clean`
2. Переустановите зависимости: `flutter pub get`
3. Попробуйте снова: `flutter run`
