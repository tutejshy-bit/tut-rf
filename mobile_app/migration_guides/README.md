Этот каталог содержит подробные инструкции по переносу функциональности из VueJS приложения `esp32cc1101Client` в Android приложение на Flutter.

- **[IMPROVEMENTS_SUGGESTIONS.md](./IMPROVEMENTS_SUGGESTIONS.md)** - Предложения по улучшениям

### Описания экранов
- **[screens/home_screen.md](./screens/home_screen.md)** - Перенос главного экрана

- **[screens/transmit_screen.md](./screens/transmit_screen.md)** - Перенос экрана передачи сигналов
- **[screens/files_screen.md](./screens/files_screen.md)** - Улучшение файлового менеджера

## Ключевые особенности переноса

### VueJS → Flutter маппинг
| VueJS компонент | Flutter эквивалент |
|----------------|-------------------|
| `Home.vue` | `HomeScreen` (улучшенный) |
| `PageRecord.vue` | `RecordScreen` (новый) |
| `PageTransmit.vue` | `TransmitScreen` (новый) |
| `PageFiles.vue` | `FilesScreen` (улучшенный) |
| `PageEditor.vue` | `EditorScreen` (новый) |
| `DeviceController` | `BleProvider` + сервисы |
| `Store (Pinia)` | `AppStateProvider` |
| `Adapters` | `FirmwareBinaryProtocol` |

### Основные функции для переноса
1. **Управление модулями CC1101** - настройка параметров, переключение режимов
2. **Запись сигналов** - детектор частот, настройки записи, управление процессом
3. **Передача сигналов** - отправка данных, управление модулями
4. **Файловый менеджер** - навигация, операции с файлами, загрузка
5. **Редактор сигналов** - создание и редактирование сигналов

## Архитектурные принципы

### 1. Модульность
Разделение на независимые модули для каждой функции:
- Device management
- Signal processing
- File management
- UI components

### 2. Единое управление состоянием
Использование `AppStateProvider` для централизованного управления состоянием приложения.

### 3. Сервисный слой
Выделение бизнес-логики в отдельные сервисы:
- `DeviceService`
- `SignalService`
- `FileService`

### 4. Переиспользование компонентов
Создание переиспользуемых виджетов для общих функций.
