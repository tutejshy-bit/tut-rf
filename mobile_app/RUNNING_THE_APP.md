# 🚀 Запуск Flutter приложения

## ✅ Текущее состояние

- **Flutter:** 3.35.2 (обновлен)
- **Android SDK:** 34.0.0 + автоматически установлены новые компоненты
- **Поддерживаемые платформы:** Android, Windows, Web
- **Зависимости:** установлены и совместимы

## 📱 Запуск на Android устройстве

### 1. Подключенное устройство
У вас есть подключенное Android устройство:
```
SM G7810 (mobile) • RFCNC06BZYJ • android-arm64 • Android 13 (API 33)
```

### 2. Запуск приложения
```bash
flutter run -d RFCNC06BZYJ
```

### 3. Что происходит при первом запуске
- Автоматически устанавливаются недостающие компоненты Android SDK
- NDK, Build-Tools, Platform 36, CMake
- Первая сборка может занять 5-10 минут

## 🌐 Запуск на Web

### 1. Запуск в Chrome
```bash
flutter run -d chrome
```

### 2. Запуск в Edge
```bash
flutter run -d edge
```

### 3. Примечания для Web
- BLE функциональность ограничена (только в поддерживаемых браузерах)
- Могут появляться ошибки DebugService (это нормально)
- Приложение работает, но без Bluetooth

## 🖥️ Запуск на Windows

### 1. Проблема с Windows
```bash
flutter run -d windows
```
**Ошибка:** `permission_handler` не совместим с Windows

### 2. Решение для Windows
Нужно обновить `permission_handler` до версии, совместимой с Windows:
```yaml
dependencies:
  permission_handler: ^12.0.1  # вместо ^11.3.1
```

## 🔧 Устранение проблем

### 1. Если сборка Android зависает
```bash
# Остановить процесс
Ctrl+C

# Очистить проект
flutter clean

# Переустановить зависимости
flutter pub get

# Попробовать снова
flutter run -d RFCNC06BZYJ
```

### 2. Если нет подключенных устройств
```bash
# Проверить устройства
flutter devices

# Запустить эмулятор (если есть)
flutter emulators

# Или использовать Web
flutter run -d chrome
```

### 3. Проблемы с правами доступа
- Убедитесь, что на Android устройстве включен режим разработчика
- Разрешите установку из неизвестных источников
- Подтвердите отладку по USB
