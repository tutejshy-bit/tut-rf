# План переноса VueJS приложения в Android (Flutter)

## Обзор проекта

VueJS приложение `esp32cc1101Client` представляет собой веб-интерфейс для управления ESP32 устройством с модулями CC1101. Основные функции:
- Подключение к устройству через Web/Serial
- Управление модулями CC1101 (запись, передача, сканирование)
- Файловый менеджер
- Редактор сигналов
- Детектор частот

## Текущая архитектура VueJS

### Основные компоненты:
1. **App.vue** - главный компонент с диалогом подключения
2. **Router** - маршрутизация между страницами
3. **Store (Pinia)** - управление состоянием
4. **DeviceController** - управление устройством
5. **Adapters** - адаптеры для различных типов подключения

### Страницы:
- **Home** - отладочная информация и состояние устройства
- **Record** - запись сигналов с настройками CC1101
- **Transmit** - передача сигналов
- **Files** - файловый менеджер
- **Editor** - редактор сигналов

### Адаптеры подключения:
- **WebAdapter** - HTTP подключение
- **SerialAdapter** - Serial подключение
- **ServerSideEventsAdapter** - SSE
- **WebSocketAdapter** - WebSocket

## Текущая архитектура Android

### Основные компоненты:
1. **BleProvider** - управление BLE подключением
2. **FirmwareBinaryProtocol** - протокол общения с ESP32
3. **Экраны** - Home, Files, Scanner, Debug
4. **Модели** - FileItem, DetectedSignal, LogEntry
