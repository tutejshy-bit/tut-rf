# Evil Crow RF v2 Mobile Controller

Мобильное приложение для управления устройством Evil Crow RF v2 через Bluetooth Low Energy (BLE).

## Возможности

- **Поиск устройств**: Автоматический поиск ESP32 устройства по имени "EvilCrow_RF2"
- **BLE соединение**: Подключение к устройству с автоматическим обнаружением сервисов
- **Отправка команд**: Текстовый ввод и быстрые кнопки для основных команд
- **Статус соединения**: Отображение текущего состояния BLE соединения
- **Кроссплатформенность**: Работает на Android и iOS

## Установка Flutter

### Windows

   - Перейдите на [flutter.dev](https://flutter.dev/docs/get-started/install/windows)

   - Откройте "Переменные среды" в Windows

   - Скачайте [Android Studio](https://developer.android.com/studio)
   - Установите Android SDK
   - Настройте эмулятор или подключите физическое устройство

4. **Проверьте установку**:
   ```bash
   flutter doctor
   ```

## Использование

### Подключение к устройству

1. **Включите Bluetooth** на вашем телефоне
2. **Нажмите "Scan for Devices"** для поиска устройств
3. **Найдите устройство "EvilCrow_RF2"** в списке
4. **Нажмите "Connect"** для подключения

### Отправка команд

После подключения вы можете:

- **Ввести команду вручную** в текстовое поле
- **Использовать быстрые кнопки**:
  - `SCAN` - Начать сканирование RF сигналов
  - `RECORD` - Начать запись сигнала
  - `PLAY` - Воспроизвести записанный сигнал
  - `STOP` - Остановить текущую операцию

### Статус соединения

Приложение показывает:
- Текущий статус BLE соединения
- Сообщения об ошибках
- Индикатор подключения (зеленый/красный)

## Устранение неполадок

### Устройство не найдено

1. Убедитесь, что ESP32 включен и рекламирует BLE
2. Проверьте, что Bluetooth включен на телефоне
3. Попробуйте перезапустить сканирование

### Ошибка подключения

1. Убедитесь, что устройство не подключено к другому приложению
2. Проверьте, что ESP32 не в режиме сна
3. Попробуйте перезагрузить ESP32

### Приложение не компилируется

1. Проверьте версию Flutter: `flutter --version`
2. Обновите зависимости: `flutter pub upgrade`
3. Очистите кэш: `flutter clean && flutter pub get`

## Разработка

### Добавление новых команд

1. Откройте `lib/screens/home_screen.dart`
2. Добавьте новую кнопку в секцию "Quick Commands"
3. Добавьте обработку команды в ESP32 код

### Изменение UI

1. Откройте `lib/screens/home_screen.dart`
2. Измените виджеты и стили
3. Перезапустите приложение

### Отладка BLE

1. Используйте `print()` в `ble_provider.dart`
2. Проверьте консоль Flutter
3. Используйте nRF Connect для проверки BLE соединения
